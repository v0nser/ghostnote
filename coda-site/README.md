# Coda marketing site

Hand-drawn landing page for **Coda**. Separate from the Tauri app and from the older Next.js `website/` (billing / Ghost Note).

**Coda: Your work, resolved. Your mind, at peace.**

```bash
cd coda-site
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

Edit visitor copy in `src/content/site.ts`. See `ASSETS.md` to replace the first-pass doodles with hand ink.

The “See it work” block is a **simulated** front-end demo. It does not call Ollama or the desktop app.
